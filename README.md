# 부엌 셀프 설계 (kitchen-planner)

부엌 셀프 설계 웹. 부엌장은 쿠지알러 부엌 파라메트릭 원본(editorData)을 계산해 그린다.

```
npm run dev        # http://127.0.0.1:5220
npm run data       # public/kjl 다시 만들기 (환경 변수 KJL_SRC = 쿠지알러 원본 폴더, PLANNER_PUBLIC = 바닥·벽지 재질 폴더)
```

## 구성

| 파일 | 하는 일 |
|---|---|
| `tools/build_kitchen_data.py` | 원본 editordata 에서 장 모듈 30종 × 계열(유로 EO · 키친바흐 KB) · 그레이드별 도어 · 하위 모델 393개 · 재질 텍스처를 `public/kjl` 로 |
| `src/kjl/*` | 파라메트릭 모델 계산기 (resolve · geometry · doc · expr …) |
| `src/kjlLib.ts` | 카탈로그 · 모델 받기(하위 모델까지 미리) · 상품(재질 · 형번) 조회 |
| `src/plan.ts` | 설계 데이터 — 방 · 공간 구조 · 공간 요소(문 · 창 · 팬트리 · 다용도실 · 서브주방) |
| `src/autoplan.ts` | 자동 배치 — 벽 조합 × 싱크 · 쿡탑 · 냉장고 자리 변형을 원본 모듈 폭으로 채우고 점수(작업 삼각형 · 조리 공간 · 수납 · 채광 · 동선)순 |
| `src/cabinet3d.ts` · `src/kitchen3d.ts` | 원본 계산 결과 → three.js · 걸레받이 · 상판 · 타일 · 싱크 · 쿡탑 · EP · 천장 마감판 · 바 스툴 |
| `src/room3d.ts` · `src/scene.ts` · `src/plan2d.ts` | 방 · 3D 화면(카메라 쪽 벽 숨김 · 개구부 끌기) · 평면도(벽 따라 끌기 · 양 끝 폭 조절) |

## 도어 그레이드

원본 제품 패키지 분류 그대로: 유로 300 · 500 · 700 · 900 (유로 몸통, 변수 `EM_DR`) · 키친바흐 KB5 · KB7 (키친바흐 몸통, 변수 `KB_DR`). 단종 · 테스트 · Custom 은 뺐다.

## 원본에 없어 따로 만든 것

3D 메시 하위 모델(다릿발 · 싱크볼 · 수전 · 쿡탑 · 식기세척기 · 후드 기기)은 원본 메시가 없다 → 걸레받이 · 형상 · 도어 재질 패널로 대신. 상판은 쿠지알러 설계 도구가 만드는 것이라 같은 재질 라이브러리(HS스톤 등)로 직접 만든다.
