## 7. 실측 체크리스트(이케아)

- 환풍구 위치를 잰다.
- 수도 · 배수관 위치를 표시한다. 옮길 예정이면 새 위치도 표시한다.
- 콘센트 · 스위치 · 가스 배관 위치를 표시한다. 옮길 예정이면 새 위치도 표시한다.
- 라디에이터 · 환기구 · 창틀처럼 튀어나온 곳을 표시한다.
- 조리대는 커버 패널 · 돌출 길이에 30mm 를 더한다.

## 8. 자동 설비도 규칙 후보 (초안 — 확정 전)

| 장 · 기기 | 필요한 설비 | 자리(초안) |
|---|---|---|
| 싱크 | 급수(냉 · 온), 배수 | 싱크장 안. 배수는 바닥 층상 배관, 구배 1/50 이상 |
| 식기세척기 | 급수 분기(냉수), 배수(싱크 트랩 분기), 콘센트 16A | 싱크 옆 2.5m 안. 콘센트는 싱크장 안 · 전원선 1.5m 안 |
| 인덕션 · 전기레인지 | 220V 16A 전용 콘센트, 고출력은 전용 회로 | 쿡탑장 아래 |
| 오븐 | 전용 콘센트 | 오븐장 안 · 옆 |
| 후드 | 배기 덕트, 콘센트 | 덕트는 외벽 · 공용 덕트로 짧게. 콘센트는 상부장 안 |
| 냉장고 | 콘센트, 정수 모델이면 급수 | 냉장고 자리 뒤 |
| 아일랜드 | 싱크 · 쿡탑 · 콘센트가 있으면 바닥 급배수 · 전원 경로 | 골조 단계 배관 홈 · 팝업 소켓 |
| 상판 위 일반 콘센트 | 조리 공간마다 | 높이 · 개수 기준은 확인 전 |

## 확인 못 한 것 (원문이 필요함)

- 주방 콘센트 높이(mm) · 개수 · 전용 회로 기준 — KEC(한국전기설비규정) 주택 조항, LH 공동주택 전기 설계기준
- 싱크 근처 콘센트 누전차단기 의무 · 감도(15mA / 30mA) — KEC 원문
- 한국 배수관 구경 · 구배 공식 기준 — 국내 설계기준(KDS) 원문(지금은 일본 기준만)
- 레인지후드 덕트 지름(100 · 150mm) · 길이 기준, 가스레인지와 후드 법정 이격 거리 — KGS 코드 · 제조사 설명서
- 냉장고 정수 급수 조건(수압 · 관경)
- 싱크 급수 · 배수 인출 높이(벽 · 바닥에서 mm)
