# 설비 보기 — 설계 (2026-11-09)

부엌 셀프 설계 웹에 급수 · 배수 · 전기 · 가스 · 배기 · 난방 설비를 자동으로 잡아 평면도와 3D 에서 보여 주는 기능.
요청자 말은 「」로 그대로 옮겼다. 「짐작」으로 정한 곳은 요청자에게 보여 주고 고쳐 받은 뒤 확정한 것이다.
**승인 2026-11-10** — 요청자가 「내 결정」 8개에 답하고 「다 진행하고 보자」. 답은 해당 절에 「요청자 결정」으로 넣었다.

## 1. 왜 만드나

- 「평면도에도 배관과 전기 설비 가스 등의 위치 라인 구조를 보여주고, 3D 에서도 설비보기 아이콘을 추가해서 해당 설비를 체크하면 투시되듯이 3D로 보여주기해」
- 「다용도실이나 보조주방 팬트리등이 있는경우도 생각해서 같이 연계확인 되도록해」
- 「앱이 가정하고 사용자가 수정가능하게해」 — 설비가 시작되는 자리(인입점)
- 「보일러도 있어 대부분 보일러 기본 배관과 컨틀롤 장치가 부엌 밑장에 있더라고」
- 쓰임: **시공 전 상담 · 확인용.** 고객과 상담자가 「이 장 배치면 배관 · 콘센트 · 가스 · 덕트 · 난방이 이렇게 지나간다」를 같이 보고, 문제가 될 자리를 미리 안다.
- 장 배치는 자동 배치(src/autoplan.ts)가 하고 사용자가 고친다. **설비는 그 배치를 따라 자동으로 잡혀야 한다** — 싱크 · 쿡탑을 옮기면 설비도 바로 다시 잡힌다.

## 2. 목표

1. 배치안의 장 · 기기(싱크 · 쿡탑 · 식기세척기 · 냉장고 · 오븐 · 후드 · 아일랜드)와 공간 요소(다용도실 · 서브주방 · 팬트리)를 보고 설비를 자동으로 잡는다.
2. 평면도: 설비 종류마다 색이 다른 선으로 경로, 연결점은 기호(수전 · 배수구 · 콘센트 · 가스 밸브 · 덕트 출구 · 보일러 · 분배기). 종류별로 켜고 끈다.
3. 3D: 도구 막대 「설비 보기」 아이콘 → 체크 목록(급수 · 배수 · 전기 · 가스 · 배기 · 난방). 체크한 설비는 장 · 벽 · 바닥을 뚫고 보이듯 3D 관 · 선으로 나타나고, 그동안 장 · 벽 · 바닥은 반투명으로 흐려진다.
4. 인입점(시작점)은 앱이 기본 자리를 정하고, 사용자가 평면도에서 끌거나 메뉴에서 위치를 넣어 옮긴다. 옮기면 경로와 확인이 바로 다시 계산된다.
5. 연계 확인: 문제가 될 만한 곳을 「확인 필요」 알림으로 짚는다(5.7).

## 3. 하지 않는 것

- **시공 도면 수준** — 관 지름, 회로 번호, 자재 물량, 법규 적합 판정. 필요해지면 나중에 더한다.
- **확인 못 한 기준을 규칙으로 쓰기** — docs/설비-설치-기준-조사.md 「확인 못 한 것」(콘센트 높이 · 개수, 누전차단기, 국내 배수 기준, 덕트 지름 · 길이, 가스레인지 ~ 후드 법정 거리, 냉장고 급수 조건, 싱크 급배수 인출 높이)은 원문을 확인하기 전까지 판정 기준으로 쓰지 않는다. 그림의 높이 · 자리는 「가정값」으로만.
- 실제 건물 정보 가져오기(도면 · 사진 업로드), 실사(경로 추적) 모드에서 설비 보기, 견적(bom.ts)에 설비 넣기.

## 4. 실패로 보는 것

- 장 · 기기를 옮겼는데 설비가 따라오지 않아 엉뚱한 자리를 가리킴.
- 설비 보기를 꺼 둔 상태에서 화면이 느려짐 — 지금 「필요할 때만 그리기」(가만히 있으면 0장)를 깨면 안 된다.
- 설비를 켰을 때 장 · 벽이 너무 흐려져 「어느 장 밑을 지나는지」 알아볼 수 없음.
- 가정값 · 블로그 수치를 법규처럼 단정하는 문구.
- 3D 화면 오류(지금 있는 WebGPU 「지워진 버퍼로 그리기」 류) — 설비 물체를 만들고 지울 때 공유 형상 · 재질을 함부로 놓지 않는다(src/dispose.ts 규칙).

## 5. 정한 것

### 5.1 설비 종류

| 종류 | 그리는 것 |
|---|---|
| 급수 | 냉수 · 온수 두 줄(온수는 보일러에서) |
| 배수 | 기기 → 배수구(층상 배관, 바닥 속) |
| 전기 | 분전반 → 콘센트 · 전용 회로(고출력 기기) |
| 가스 | 가스 인입 → 중간밸브 → 쿡탑(가스일 때) · 보일러 |
| 배기 | 후드 → 공용 배기 덕트(벽 · 천장 가까이) |
| 난방 | 보일러 → 분배기(공급 · 환수 두 줄) → 방 쪽 바닥 난방관(방향만 짧게) · 분배기 밸브 구동기 전원 |

- **난방 방식 (요청자 결정 2026-11-10 「개별보일러」):** 늘 개별 보일러로 본다. 지역 · 중앙난방 선택지는 두지 않는다. 보일러는 가스를 받고, 온수를 싱크로, 난방 공급 · 환수를 분배기로 보낸다.

### 5.2 기기별로 필요한 설비 (조사 문서 8절 초안을 그대로 쓴다)

| 장 · 기기 | 필요한 설비 | 자리(가정) |
|---|---|---|
| 싱크 | 급수(냉 · 온), 배수 | 싱크장 안 |
| 식기세척기 | 급수 분기(냉수), 배수(싱크 트랩 분기), 콘센트 16A | 싱크 옆. 콘센트는 싱크장 안 |
| 인덕션 · 전기레인지 | 220V 16A 전용 콘센트(고출력은 전용 회로) | 쿡탑장 아래 |
| 가스 쿡탑 | 가스(중간밸브) | 쿡탑장 안 |
| 오븐 | 전용 콘센트 | 오븐장 안 · 옆 |
| 후드 | 배기 덕트, 콘센트 | 덕트는 공용 배기 덕트로. 콘센트는 상부장(후드장) 안 |
| 냉장고 | 콘센트(정수 모델이면 급수 — 지금 냉장고는 비정수로 본다) | 냉장고 자리 뒤 |
| 아일랜드 | 팝업 콘센트 하나는 늘(요청자 ok). 쿡탑 · 싱크를 아일랜드로 옮겼으면 그 설비(전용 회로 또는 가스 · 급수 · 배수) | 바닥 속 경로, 콘센트는 팝업 소켓 |
| 상판 위 일반 콘센트 (요청자 결정 2026-11-10 「별도 배치」) | 일반 회로 하나 | **자동으로 깔지 않는다.** 설비 메뉴 「콘센트 추가」로 사용자가 따로 놓는다 — 벽 위 자리 · 높이(처음 높이 1,100 가정), 평면도에서 끌어 옮기고 메뉴에서 위치를 넣거나 지운다. 설계에 저장 |

- 쿡탑이 인덕션인지 가스인지는 고른 가전(src/catalog.ts 의 hob 종류)으로 가른다. 기본 쿡탑은 인덕션(밀레 4구).
- **후드일체형 인덕션 (내 결정):** 카탈로그 쿡탑 27종 중 6종이 후드일체형(다운드래프트)이다. 이걸 고르면 배기는 쿡탑에서 시작해 하부장 밑 · 걸레받이 속으로 벽 덕트까지 그리고, 위 후드 덕트는 그리지 않는다. 실제로 없을 덕트를 그리면 4절 실패(엉뚱한 자리)다. 자동 배치가 그 위에 후드장을 두는 것은 이번 범위 밖이다.
- **아일랜드 싱크 (요청자 결정 2026-11-10 「아일랜드 싱크 추가」):** 이번에 같이 만든다.
  - 싱크장을 아일랜드로 끌어 놓을 수 있다(쿡탑처럼). 설계에는 `fix.sink = { island: true, c }`(아일랜드 위 가운데 자리)로 남는다.
  - 식기세척기는 따로 옮기지 않았으면 싱크 옆(아일랜드 안)에 같이 간다. 아일랜드가 짧아 안 들어가면 빼고 알린다.
  - 아일랜드 길이는 싱크(+식기세척기, 쿡탑도 있으면 쿡탑)가 들어가는 만큼은 늘 확보한다.
  - 설비: 냉 · 온수와 배수가 바닥 속으로 벽(인입점)에서 아일랜드까지 간다 → 「골조 단계 배관 홈 · 난방관 위로」와 배수 기울기 확인(5.7)이 늘 따라온다.

### 5.3 인입점 — 앱이 정하고 사용자가 고친다

| 인입점 | 앱이 정하는 처음 자리 |
|---|---|
| 배수구 · 급수 인입 | 싱크가 있는 벽 아래(바닥). 싱크를 옮기면 따라간다 |
| 분전반 | 거실 쪽(트인 쪽) 벽 |
| 가스 인입 | 다용도실이 있으면 다용도실 바깥 벽, 없으면 쿡탑이 있는 벽 |
| 공용 배기 덕트 | 쿡탑 위 천장 가까운 벽 |
| 보일러 | 다용도실 벽, 없으면 가스 인입 근처 |
| 난방 분배기 | 싱크장 아래(하부장 밑) |

- 평면도에 기호로 보이고, 창 · 문처럼 **끌어서 옮기거나 메뉴에서 위치를 넣는다**(창 · 문 메뉴의 「왼쪽 벽까지 · 오른쪽 벽까지」 같은 방식).
- **사용자가 한 번 옮긴 인입점은 그 자리에 고정**되고, 옮기지 않은 것만 배치를 따라간다. 「자동 위치로」로 되돌린다.
- 인입점 자리는 설계(Design)에 들어가 **설계 파일 저장 · 불러오기 · 되돌리기(최대 50)** 에 함께 들어간다.
- **어디에 붙고 어디로 옮기나 (내 결정)** — 인입점은 두 가지다.
  - **벽 인입점** — 분전반 · 가스 인입 · 공용 배기 덕트 · 보일러. 벽(부엌 네 벽 · 날개벽 · 다용도실 · 서브주방 · 팬트리의 벽) 위 자리와 높이. 끌면 가장 가까운 벽으로 붙고, 메뉴에서 「왼쪽 벽까지 · 오른쪽 벽까지 · 바닥에서 높이」를 넣는다.
  - **바닥 인입점** — 배수구 · 급수 인입 · 난방 분배기. 부엌 바닥 위 자리. 끌면 바닥 어디로든, 메뉴에서 벽까지 거리를 넣는다.
  - 고정한 인입점은 **부엌 좌표(mm) 그대로** 저장한다. 방 크기 · 공간 요소를 바꿔 그 자리가 없어지면 가장 가까운 알맞은 벽 · 바닥으로 붙인다(지우지 않음). 다용도실을 빼면 그 안 인입점은 부엌 쪽 가장 가까운 벽으로.
  - 분전반 기본 자리 — 날개벽이 있으면 날개벽, 없으면 트인 쪽과 맞닿은 옆 벽 끝. 트인 쪽이 없으면 정면 벽 맞은편 벽.
  - 요청자(2026-11-10 「적용한 상태보고 추가 진행」): 이대로 만들어 보여 준 뒤 보고 더 고친다.

### 5.4 다용도실 · 서브주방 · 팬트리 연계

- **다용도실**: 세탁기 · 건조기 · 세탁 싱크(급수 · 배수 · 전기), 보일러 기본 자리.
- **서브주방(보조주방)**: 싱크 · 쿡탑 · 후드(급수 · 배수 · 전기 또는 가스 · 배기).
- **팬트리**: 콘센트와 조명(짐작으로 정함).
- 그 공간 안 기기는 지금 3D 에 없다 — 공간 안쪽에 가정 자리로 기호를 둔다.
- **서브주방 쿡탑 (내 결정):** 부엌 쿡탑 종류를 따른다(인덕션이면 전용 회로, 가스면 가스). 따로 고르는 칸은 만들지 않는다.
- **공간 기기 끄기 (내 결정):** 이번엔 기기마다 끄지 않는다. 공간 요소가 있으면 그 공간의 가정 기기가 다 보인다.
  여기서 「끄기」는 설비 보기에서 그 기기의 설비를 **숨기는 것(보이기 · 숨기기)** 이다. 기기의 작동 상태(켜짐 · 꺼짐)를 보거나 판정하는 기능은 없다.
  요청자가 2026-11-10 「동작상태 체크??」라고 물어서 결과 보고 때 이 뜻을 다시 설명한다.
- 「연계」는 부엌과 같은 계통으로 이어 보여 주는 것이다 — 예: 서브주방 싱크 배수가 부엌 배수와 어디서 만나는지, 가스가 어디로 들어와 쿡탑 · 서브주방 · 보일러로 갈라지는지.

### 5.5 평면도

- 지금 「동선」 겹친 층처럼 평면도 위에 겹쳐 그린다(src/plan2d.ts drawFlow 방식). 장 · 아일랜드 고르기를 막지 않는다 — 인입점 기호만 누르고 끈다.
- 종류마다 색 선 + 연결점 기호, 종류별 켜고 끄기(평면도 머리의 「동선」 단추 옆이든 3D 체크 목록과 같은 상태든 — 5.8).

### 5.6 3D 설비 보기

- 도구 막대에 「설비 보기」 아이콘. 누르면 체크 목록 팝업(지금 「보기」 #look-pop 같은 모양).
- 하나라도 체크하면: 그 설비가 3D 관 · 선으로 장 · 벽 · 바닥을 뚫고 보이고(가려도 보이게), 장 · 벽 · 바닥은 반투명으로 흐려진다. 모두 끄면 원래 모습.
  - 개정 2026-11-10(사용자 「설비 보기에서 공간은 원래대로 보여줘야해」): 반투명은 부엌 장 · 가전만. 벽 · 바닥 · 천장 · 거실 · 벽 너머 공간과 벽 타일 · 식탁은 원래대로 보인다. 그래서 바닥 속 관은 3D 에선 바닥 면 바로 위에 그리고(평면도는 점선으로 바닥 속), 벽 · 공간에 가려진 이름표는 숨긴다.
- 도구 막대 규칙: 아이콘은 팝업이 열렸거나 설비가 켜져 있을 때만 검게(다른 아이콘과 같다).
- 실시간(raster) 모드에서만. 실사 모드로 가면 설비 보기는 꺼진다.

### 5.7 연계 확인 — 「확인 필요」 알림

| 확인 | 판정(가정값은 상수로 두고 「가정」 표시) |
|---|---|
| 배수 경로가 길어 기울기를 못 잡음 | 배수 경로 길이 × 1/50 이 바닥 속 배관 여유(가정)를 넘을 때 |
| 식기세척기가 싱크에서 멂 | 수전 ~ 식기세척기 2.5m 넘음(삼성 설치 가이드) |
| 후드 덕트가 너무 김 | 덕트 길이 · 꺾임 수가 가정값을 넘을 때 — 기준 원문 미확인이라 「확인 필요」로만 |
| 고출력 기기 전용 회로 | 인덕션 · 오븐 · 식기세척기마다 「전용 회로 필요」 안내(개수 판정은 하지 않음) |
| 다용도실 · 서브주방과 배관을 같이 씀 | 만나는 자리 표시 |
| 분배기가 있는 하부장 | 그 장이 서랍장 · 식기세척기 · 오븐이면 경고 — 점검하려면 바닥판을 열 수 있는 장이어야 한다 |
| 아일랜드 바닥 경로 × 바닥 난방 | 아일랜드로 가는 바닥 경로(팝업 콘센트 · 쿡탑 전원 · 가스 · 싱크 급배수)가 있으면 늘 「골조 단계에서 배관 홈 필요 · 난방관 위로」. 부엌 바닥 전체를 난방 바닥으로 본다(요청자 ok — 온돌이라 바닥 전체가 난방관) |

- 알림은 지금 배치안 알림(warnings)과 같은 자리에 「설비」 표시를 달아 보인다. 문구는 「확인 필요」 · 「권장」 — 법규처럼 단정하지 않는다.

### 5.8 자세함 정도

- 기기 위치, 배관 · 전선 경로, 연결점, 기기 이름까지. 관 지름 · 회로 번호 · 자재 물량은 없다(3절).

### 5.9 저장 위치

- 인입점 자리(사용자가 옮긴 것) — 설계(Design)에 저장(5.3).
- 설비 보기 켜짐 · 종류별 체크 — 화면 설정이라 보기 설정(viewCfg, 브라우저 localStorage)에.

## 6. 빌더가 정하는 것

- 경로를 잡는 방법(벽 · 장 뒤 · 바닥을 따라 꺾이는 경로 등), 3D 관 굵기 · 모양 · 색, 기호 모양, 반투명 정도와 방법, 메뉴 배치, 모듈 나누기.
- 다용도실 · 서브주방 · 팬트리 안 기기의 기본 자리.
- 가정값(바닥 속 배관 여유, 덕트 길이 · 꺾임 한도, 콘센트 높이 등) — 상수 한 곳에 「가정」 주석과 함께.
- 평면도 종류별 켜고 끄기를 3D 체크 목록과 같은 상태로 묶을지.
